# さんすうの森 効果音・選定仕様書

作成・更新：2026-11-02 / 素材セット：基本v1＋戻る・らいおん・ステージ選択v2

## 要望と方針

ユーザーの要望：「SEはまなびくえすとで使っていたサイトみたいにしよう」。まなびクエストの出典を確認し、Kenneyのゲーム用効果音素材を使う方針にした。

木漏れ日の森のBGMに合わせ、短い操作音、木や材料袋の質感、正解を知らせる確認音を組み合わせる。配布素材をそのまま大きい音で鳴らすのではなく、役割ごとに長さと音量を調整する。

## 音の対応と選んだ理由

| 場面 | 配布パック / 素材名 | 加工・選定理由 |
| --- | --- | --- |
| 地図・メニュー操作 | Interface Sounds / click_001 | 短いクリック。操作を邪魔しない長さ |
| 戻る（v2） | RPG Audio / bookFlip1 | 紙をめくる音で、戻る動きを柔らかく表す |
| らいおんに触れる（v2） | Impact Sounds / impactWood_light_001 | 小さな木の音で触れた手応えを表す |
| ステージ選択（v2） | Interface Sounds / confirmation_001 | 通常操作と区別する短い決定音。地図のテントと一覧で共通 |
| 正解 | Interface Sounds / confirmation_002 | 成功を知らせる確認音。再表示だけでは鳴らさない |
| 考え直す | Interface Sounds / question_002 | 問いかけの音を小さめにし、強い警告の印象を抑える |
| 材料をもらう | RPG Audio / handleSmallLeather | 材料袋を扱うような質感を添える |
| 建物を作る・育てる | Impact Sounds / impactWood_medium_000 | 木の音を3回、小さく重ねる。成功時だけ鳴る |
| 物を配置する | Impact Sounds / impactWood_light_000 | 置いた手応えを、短い木の音で表す |
| キャンプをクリア | Interface Sounds / confirmation_004 | 正解と区別する確認音。材料音を止めてこちらを優先 |

効果音ON時の確認音は「正解」の音を共用。ドラッグ中に音を連打しない。らいおんは触れた時に反応する。

## 加工と再生の仕様

- 元素材はKenney配布のOgg。元ファイル名とSHA-256を `manifest.json` に記録。
- モノラル22.05 kHz / 16-bit PCM WAVへ変換。前後の余分な無音を短くし、端に小さなフェードを付ける。
- 役割別の平均音量を調整。ピークは0.60以下を確認する。
- 建築音のみ0秒・0.09秒・0.20秒に木の音を重ね、2回目以降を弱くする。
- 採用した9ファイルの合計は107,142 bytes。効果音をONにした時だけ読み込み、デコード結果をキャッシュする。
- 個別の素材が読めない場合は、従来の小さいベル音などを予備として使う。再生できたKenney素材はそのまま使う。
- 効果音OFFはBGMを止めない。BGM、学習の記録、材料の数、建物、らいおんの位置を維持する。

## 試作と確認の記録

1. まなびクエストのクレジットで配布元を確認。
2. Kenney公式の3パックとCC0表記を確認。
3. 9場面へ素材を対応付け、音量・長さを加工。
4. 順番に聴ける16秒の[試聴音源](../../common/audio/forest-se-preview-v1.mp3)を作成。
5. ゲームの出来事に結び付け、再生状態・読み込み失敗・OFF操作を検証。

試聴の順番：**操作 → 戻る → らいおん → 正解 → 考え直す → 材料 → 建築 → 配置 → クリア**。

自動確認では9種類の対応、正解音の重複防止、材料音からクリア音への切り替え、BGMとの独立、タブ非表示時の停止、読込中のOFF、素材の一部が読めない場合を検証した。音の好みやBGMとのなじみ方は、今後の試聴コメントに基づいて改訂する。

## 再現手順と出典

Python、NumPy、imageio-ffmpegを用意。以下の公式ページから無料パックを取得し、このフォルダの `raw/` に `interface.zip`、`impact.zip`、`rpg.zip` として保存し、`python prepare.py` を実行する。

- [Kenney / Impact Sounds](https://kenney.nl/assets/impact-sounds)
- [Kenney / RPG Audio](https://kenney.nl/assets/rpg-audio)

作者：Kenney。各パックのライセンス：CC0 1.0。配布されたライセンス文書も `LICENSE-interface.txt`、`LICENSE-impact.txt`、`LICENSE-rpg.txt` に保存。元素材・加工後素材のハッシュ、使用箇所、測定値は [manifest.json](manifest.json) を参照。

この変更は[「こもれびの小道」BGMの仕様・改訂履歴](../music/SPEC.md)と別に管理する。今後の音の変更も、要望・試作・コメント・改訂の順に追記する。

## 第2版の改訂記録

ユーザーのコメント：「戻る音と、キャラをさわったときのおと、ステージを選んだ時の音変えたい」。戻る音とらいおんの音を差し替え、ステージには専用の音を設けた。地図のテントと一覧のどちらを選んでも、ステージ開始に合わせて1回鳴らす。

[新しい3音の試聴](../../common/audio/forest-se-preview-v2.mp3)の順番は、**戻る → らいおん → ステージ選択**。3素材の合計は49,428 bytes。BGMと他の効果音は維持する。旧素材はv1として残し、今回の選定・測定値は [manifest-v2.json](manifest-v2.json) に保存する。

再現時は、前述の3パックを `raw/` に用意し、`python prepare-v2.py` を実行する。第1版の作成手順と試聴音源も引き続き保存する。
