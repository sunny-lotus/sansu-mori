# さんすうの森 BGM制作仕様書

更新日：2026-11-02 / 曲名：**こもれびの小道** / 現在の制作版：v2

## 目的と制作方針

ユーザーが選んだ方向は「木漏れ日の森：やさしく、学習に集中できる」。問題を考えている間も、らいおんと遊ぶ間も、木陰にいるような穏やかさが続く曲を目指す。

音の変更は、要望 → 音楽の設計 → 楽譜データ → 試作音源 → 試聴コメント → 改訂 → 実装・確認の順に記録する。バージョンを残し、何を理由に変えたか追えるようにする。

## 音楽の設計

| 項目 | 仕様 | 意図 |
| --- | --- | --- |
| 拍子 | 6/8拍子 | 2つの大きな拍で、ゆったり揺れる |
| テンポ | 付点四分音符＝60（八分音符1個＝1/3秒） | 急がせる印象を抑える |
| 長さ | 16小節、32秒のループ | 短い学習にも連続した学習にも使う |
| 調性 | ト長調を中心にホ短調の色も使う | 明るさに、静かな木陰の表情を添える |
| 和声 | maj7・add9など、響きに余白がある和音 | 派手な終止感を抑え、自然に周回する |
| 主旋律 | フルート。主にE4〜E5、1小節1〜2音 | 息の感じと、考えるための休符を作る |
| 伴奏 | 柔らかいマリンバ、1小節3音 | 木の質感。第2の大きな拍を強く打たない |
| 低音 | チェロのピチカート、1小節1音 | 足元を支える。重い持続低音にしない |
| 光の音 | 小さいグロッケン、4小節に1音 | 木漏れ日のきらめきを、控えめに添える |
| ドラム・環境音 | 今回は使わない | 鳥声などを効果音や通知と混同しにくくする |
| 空間 | 短く小さい反射音、狭いステレオ配置 | 広がりを付け、はっきりした反復エコーを避ける |

※音名は中央のドをC4（MIDI 60）とする表記。音源ファイル名のオクターブ番号とは異なる場合がある。

## フレーズと強弱

| 小節 | 場面のイメージ | 音楽の動き |
| --- | --- | --- |
| 1〜4 | 木陰へ入る | ソ・シ・レを中心に、控えめに始まる |
| 5〜8 | 木漏れ日が広がる | ミまで少し上がり、明るくふくらむ |
| 9〜12 | 静かな木陰 | ホ短調の色を使い、低めの旋律で落ち着く |
| 13〜16 | 小道をひと回り | やさしく持ち上げ、ソに帰って次の周回へ |

v2では各小節の音量目標を0.70〜1.20の範囲に置き、コサイン曲線で滑らかにつなぐ。隣接する目標の移行には2秒かける。一音だけが急に飛び出すアクセントを追加しない。フルートの一音の中にも、小さくふくらんで戻る息の強弱を付ける。

全体の平均音量はv1とほぼ同じに保つ。大きく聞かせるための音量増加と、表情を付けるための強弱を区別して調整する。

## 再生と実装

- BGMと効果音のON/OFF、音量、保存済み設定を維持する。初回はOFF。
- マスター音源をMP3に書き出し、試聴とサイトで同じ音源を使う。
- サイトでは必要になった時だけ読み込み、デコード後に最初の音を再生する。
- ループ範囲は0〜32秒。前の周回の余韻を含めてレンダリングし、継ぎ目を確認する。
- タブを離れた時は停止。戻った時は設定に従って先頭から再開する。
- 読み込みに失敗した場合は既存の軽い合成音の曲を使い、画面に表示する。
- 正解・材料・建物などの既存の効果音と学習の記録は維持する。

## ファイルと再現方法

- [v1の作曲データ](komorebi-v1/score.json) / [v2の作曲データ](komorebi-v2/score.json)
- [v1の試聴](../../common/audio/forest-komorebi-v1.mp3) / [v2の試聴](../../common/audio/forest-komorebi-v2.mp3)
- 各版の `make-score.py`、`render.py`、`sources.json`、`verification.json` を保存する。

Python、NumPy、imageio-ffmpegを用意し、対象の版のフォルダで以下を実行する。

```text
python make-score.py
python render.py
```

必要な録音素材は `sources.json` のURLから取得し、SHA-256を照合する。`score.json` が音符の根拠で、`render.py` が音色・強弱・残響・書き出し処理の根拠。FFmpegの版などによって圧縮後のバイト列は変わる場合がある。

## 確認したことと、次に聴くこと

v2書き出し結果：32.000秒、ステレオ22.05 kHz、384,984 bytes。圧縮後のピーク約0.208、RMS約0.0522。先頭と末尾のサンプル差は約0.000032。クリッピングと大きな不連続がないことを数値で確認した。

自動確認は音割れ・長さ・再生状態・保存・効果音との独立を対象とする。「森らしい」「集中しやすい」「強弱が自然」は数値だけでは確定できないため、試聴で確認する。次は、5〜8小節のふくらみが強すぎないか、9〜12小節が静かすぎないか、繰り返しで気にならないかを聴く。

## 使用素材

オリジナルの旋律・和声・編曲に、実際の楽器を録音した素材を使用。

- フルート・チェロ：[VSCO 2 Community Edition](https://github.com/sgossner/VSCO-2-CE)、CC0 1.0。録音：Sam Gossner、Simon Dalzellほか、素材編集：Elan Hicklerほか。
- マリンバ・グロッケン：[VCSL](https://github.com/sgossner/VCSL)、CC0 1.0。Versilian Studiosと協力演奏者。
- フルートは持続音を選び、必要な長さを取り出し、モノラル化・音量調整。既存の他の素材は短く加工された音源を使用。取得先とハッシュは各版の `sources.json` に記録。
